# Robotics textbook

The expanded edition is **AI_Humanoid_Robotics_Complete_Textbook.pdf** (803 pages).

It contains the project guide, 17 practical lessons, 70 extended numerical labs,
420 worked parameter cases, complete code, diagrams, exercises and source references.

- `humanoid_lab/`: actual pinned-model simulation projects and original tests.
- `expanded_lab/modules/`: 70 standalone numerical teaching programs.
- `expanded_lab/results/`: executed case data and graphs.
- `textbook_source/`: editable complete manuscript, PDF builder and validation manifest.
- `research/asimov-1/`: pinned upstream model and design assets.

The earlier compact PDFs remain available as earlier editions.
